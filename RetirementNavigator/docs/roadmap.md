# Roadmap

## MVP milestones
M1 Foundation → M2 Accumulation engine, income, accounts → M3 Forecasting → M4 Retirement income →
M5 Scenarios → M6 Monte Carlo → M7a Calculators → M7b Insights, export, print → M8 Quality.
Gates and traceability: see `docs/BRIEF.md` §11 and `docs/STATUS.md`.

## Beyond MVP (not planned for the MVP)
- Roth conversions (and conversion-ladder planning)
- Backdoor Roth contributions
- Spousal IRA for a non-working spouse
- Deductible traditional IRA (with its phase-outs)
- Additional filing statuses (head of household, married filing separately, qualifying surviving spouse)
- Social Security earnings test; survivor early-claim reduction; SS death benefit
- State-specific tax rules; itemized deductions; credits; AMT, NIIT, IRMAA
- Allocation glide paths; fat-tailed or regime-switching return models
- Beneficiary RMD rules; estate planning; long-term-care modeling
