# Noct Character Model

An original 3D game character drawn with [three.js](https://threejs.org/) in a single HTML file:
a wandering duelist in a wide-brimmed hat and long black coat, resting both hands on a longsword
planted point-down in front of him. The look is cel-shaded, in the style of an anime character sheet.

The model is built in code from simple shapes (no imported mesh or textures), so every part can be
edited in `index.html`.

## Run

Open `index.html` in a browser. It needs an internet connection the first time, to load three.js
(r128) and the fonts from their CDNs. There is no build step.

## Controls

- Drag to turn the character, scroll or pinch to zoom.
- **Wind** sets how hard the coat, scarf, ribbons and hair blow.
- **Colour** swaps the accent colour (scarf, coat lining, blade glow, eyes, moon).
- **Turntable** spins the camera slowly around him.

## Parts

Hat with band, pin and ribbons; white hair with a long tail; high collar and scarf; double-breasted
coat with a wind-blown skirt; armoured left arm and layered shoulder plates; belt, sash, trousers and
strapped boots; longsword with a glowing fuller.
